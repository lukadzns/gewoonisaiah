# Nexa lettertypes

Nexa is een commercieel lettertype en mag niet zomaar worden meegeleverd.
Koop of download de licentie en zet deze bestanden in deze map:

- `Nexa-Bold.woff2`  (koppen)
- `Nexa-Light.woff2` (lopende tekst)

De site pakt ze automatisch op (zie `@font-face` bovenaan `app/globals.css`).
Zolang ze ontbreken, toont de site Montserrat Bold en Light, dat er sterk op lijkt.
